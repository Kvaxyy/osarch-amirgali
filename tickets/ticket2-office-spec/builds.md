# Ticket 2 — Four role-based builds

**Price check date:** 2026-11-20. Totals include one monitor and one licensed Windows 11 Home OEM license per machine. Detailed component prices and sources are in `budget.csv`.

## Compatibility baseline

All four systems use an AM4 Ryzen 5 5600GT, ASUS Prime B550M-K motherboard, DDR4 memory, and a 1 TB M.2 NVMe SSD. The processor and board use the AM4 socket; the board supports DDR4 and an M.2 SSD. The micro-ATX board fits the AeroCool CS-111-G-BK-V1 case. The DeepCool AG200 cooler supports AM4 and is included because the CPU is listed as OEM without a cooler. The RTX 3050 in the Designer system is a PCIe graphics card; that build uses a 650 W PSU. The other systems use integrated graphics and a 500 W PSU. Check stock, exact model, and BIOS compatibility with the vendor before purchase.

Each build includes the Philips 24E1N1200A/01 monitor (23.8-inch IPS, 1920 × 1080) at **52,100 KZT**. Windows 11 Home OEM is included because the required accounting and design software was not specified; confirm the actual software and license requirements before buying.

## Build 1 — Accountant

- **Load:** 6–8 hours/day in accounting software, spreadsheets, browser, email, and PDF documents; assume 10–20 browser tabs and one large workbook open at once.
- **Bottleneck:** 16 GB RAM is the likely first limit if spreadsheets, browser tabs, and accounting software grow together. Integrated graphics are sufficient for office display output.
- **Trade-off:** Keep 16 GB and integrated graphics to avoid paying for a discrete GPU this assumed workload does not need. Add memory later if usage shows pressure.
- **Parts:** Ryzen 5 5600GT; ASUS Prime B550M-K; 16 GB DDR4-3200; Kingston NV3 1 TB NVMe; AeroCool VX PLUS Stealth 500 W PSU; AeroCool CS-111-G-BK-V1 mATX case; DeepCool AG200 AM4 cooler; Philips 24E1N1200A/01 monitor; Windows 11 Home OEM.
- **Total:** **461,330 KZT**.

## Build 2 — Sales manager

- **Load:** 6–8 hours/day in CRM/browser, email, spreadsheets, presentations, and video calls; assume 20–30 tabs and a call while CRM and a spreadsheet remain open.
- **Bottleneck:** Memory pressure from many tabs and a video call is the likely first complaint. The 6-core CPU and integrated graphics are adequate for this assumed office workload.
- **Trade-off:** Keep 16 GB and integrated graphics, spending on the required SSD, licensed OS, and monitor instead. Confirm browser compatibility with the company CRM.
- **Parts:** Same components as the Accountant system.
- **Total:** **461,330 KZT**.

## Build 3 — Web developer

- **Load:** 7–9 hours/day with an editor, browser, local database, and several containers or development services running together; assume 20–40 browser tabs.
- **Bottleneck:** Memory is the first likely limit, so this system starts at 32 GB (2 × 16 GB DDR4-3200). CPU time may be next during parallel builds; integrated graphics are acceptable unless the role includes GPU compute.
- **Trade-off:** Spend on 32 GB RAM while retaining the 6-core CPU and integrated graphics. This avoids buying a GPU for a workload assumed to be heavier on CPU, memory, and storage.
- **Parts:** Ryzen 5 5600GT; ASUS Prime B550M-K; 32 GB DDR4-3200 (2 × 16 GB); Kingston NV3 1 TB NVMe; AeroCool VX PLUS Stealth 500 W PSU; AeroCool CS-111-G-BK-V1 mATX case; DeepCool AG200 AM4 cooler; Philips 24E1N1200A/01 monitor; Windows 11 Home OEM.
- **Total:** **526,320 KZT**.

## Build 4 — Designer

- **Load:** 6–8 hours/day in 2D illustration/layout and light video; assume several large layered files plus browser/reference images open together.
- **Bottleneck:** GPU acceleration and 6 GB VRAM are the likely limits for effects, large canvases, and video export; 32 GB RAM helps with layered files. Confirm color-accuracy needs before purchase.
- **Trade-off:** Add an RTX 3050 6 GB and 32 GB RAM, but retain a basic 23.8-inch 1080p monitor and entry-level GPU to keep the system affordable. This is intended for the assumed non-3D workload.
- **Parts:** Ryzen 5 5600GT; ASUS Prime B550M-K; 32 GB DDR4-3200 (2 × 16 GB); Kingston NV3 1 TB NVMe; MSI MAG A650BN 650 W PSU; AeroCool CS-111-G-BK-V1 mATX case; DeepCool AG200 AM4 cooler; Philips 24E1N1200A/01 monitor; Windows 11 Home OEM; Palit RTX 3050 StormX OC V1 6 GB.
- **Total:** **709,110 KZT**.

### Buying ready-made instead

Treat these totals as target prices, not as proof that pre-built computers cost the same. A pre-built quote should meet the same minimums (16 GB RAM, 1 TB SSD, licensed OS, monitor), state the exact PSU, motherboard, and GPU models, include warranty and delivery, and be dated. Compare the quote with the corresponding role build before ordering.
