# Compatibility evidence

PCPartPicker does not list the exact Kazakhstan SKUs used in these builds.
I did not substitute similar models because that could misrepresent the parts.

Compatibility was checked by matching the CPU socket, motherboard memory type,
SSD interface, case form factor, cooler socket, GPU clearance, and PSU capacity.
See `builds.md` for the compatibility notes and `budget.csv` for the exact
models and Kazakhstan vendor listings.
